OTD RACE TIMER — BRIDGE READY v32

This build adds:
- A meet/race main menu.
- Pairing by Supabase race code.
- Offline race mode.
- Unique finish IDs and finish numbers.
- A persistent outgoing Bridge message queue.
- Automatic retries every 3 seconds.
- Undo cancellation messages.
- Race-finished messages.
- A synchronization-aware end-race summary.
- Return to Main Menu for the next race.

The timer requires the Supabase tables and policies included with the Windows
Bridge starter project. Enter the Supabase project URL, public anon key, and
the pairing code generated by the Windows Bridge.

The timer remains fully usable in Offline Mode if the Bridge or Internet is
unavailable.
